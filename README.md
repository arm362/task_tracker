## Features

- 📋 **View Task List** — Displays task ID, name, description, status, and creation/update timestamps.
- ➕ **Add Tasks** — Create new tasks.
- ✏️ **Update Tasks** — Modify name, description, or status (`todo`, `in-progress`, `done`).
- 🗑️ **Delete Tasks** — Remove tasks by their unique ID.

## ️ Installation & Setup

### Prerequisites
- **Python 3.10** or higher (uses `match/case` structural pattern matching).

### Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arm362/task_tracker.git
   cd task_tracker
   ```
   
2. **Run program**
   ```commandline
      python main.py
   ```
